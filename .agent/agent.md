# AI向け引き継ぎ

## 目的と環境

- Ollama上のQwen3 8BとPDFMathTranslate-nextを使い、英語PDFを日本語に翻訳する。
- Windows 11、WSL2、Docker Compose、Python 3.12のDev Containerを使用する。Ollamaの動作は確認済み。
- Dev ContainerからのOllama接続先は `http://ollama:11434`、モデル名は `qwen3:8b`。モデルはDockerボリューム `ollama_data` に保存する。
- DockerコマンドはWSL側から実行する。Dev Container内にDocker in Dockerを導入する必要はない。

## 副作用の扱い

- このプロジェクトでは、AWSリソースなどへのアクセスを副作用として扱う。
- 標準的なファイルの読み書きや、機能が限定されたコマンドの呼び出しは計算として扱う。`pdf2zh_next` の呼び出しも同様。
- したがって、ジョブ管理のファイル操作を `libs` に置いてよい。その他に扱いが不明な場合は開発者に確認する。

## 設計上の注意

- SR1000は `pdf2zh_next` を直接呼び出さず、別モジュールを介する。
- ページ単位で進捗を保存して再開する。モデル変更後の再開も許可する。
- 翻訳エラーを記録して処理を継続し、失敗したページの位置には失敗を示すPDFページを出力する。
- Job IDとログの場所は開始時に表示し、ログは `tail -f` で確認できるようにする。

## 実装前に確認すること

- 翻訳に失敗したページは再開時に再処理する。
- 仕様中のモジュール実行例が、実際のパッケージ構成と実行ディレクトリで動作するか確認する。
- ページ指定、翻訳結果、PDF結合、日本語テキストの生成について、使用するライブラリの実際の動作を確認する。
