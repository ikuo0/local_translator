- SR1000
  - PDFの英語→日本語翻訳実行
  - SF001_to_html
    - PDFを1ページ毎にHTML化する
  - SF002_preproc
    - HTMLからスタイルタグを削除し、IDを付与する
  - SF003_translate
    - 行の定義：**タグ単位**（b, strong, i, em, span, font, u タグ削除済みのため）
    - 内部フォーマット：タグ単位でテキストを抽出
      ```
      id000000 タグ内のテキスト全て
      id000001 タグ内のテキスト全て
      id000002 タグ内のテキスト全て
      ```
    - 翻訳対象テキストを1500文字以下で区切る
      - 100行あった場合に先頭から行単位で連結していき、30行目で1500文字を超えたら、29行目までの結合とする
      - 単体で1500文字を超える場合は、その行だけ翻訳にかける
    - 区切ったテキストを翻訳にかける
    - ID単位の翻訳結果を収集する
    - 翻訳時は実行引数によるプロンプト固定部を設定（`XXXのマニュアルである` など前提条件の付与）
  - SF004
    - ID別にテキストを復元しHTMLとして保存（翻訳元とは別ファイルで保存）
  - SF005
    - SF004で作成したHTMLをまとめ、`SF005/pdf/入力ファイル名jpn.pdf` に保存する
    - `SF005/text/page_000001.txt` のようにページごとのテキストを保存する
    - 図はページ内の出現順に `[[figure1]]` などで示し、表は `[[table begin]]` と `[[table end]]` で囲む。段組や改行などのレイアウト上の区切りは半角空白にする
    - SF001の原文HTMLとSF004の翻訳HTMLをMarkdownに変換し、それぞれ `SF005/md_en/page_000001.md` と `SF005/md_jp/page_000001.md` のように保存する
